Commercial Intelligence Dashboard - Power BI

```

Project Overview

I developed an end-to-end Commercial Intelligence Dashboard to transform raw sales data into meaningful business insights. The project involved data cleaning and preparation, SQL database development, data analysis, and interactive dashboard development using Power BI.

The goal was to help business stakeholders, particularly the CEO and CMO, quickly understand sales performance, profitability, regional performance, product and category performance, and order status.

Tools Used

  • Excel / Power Query – Data cleaning and preparation
  • MySQL – Database creation, data storage, and SQL analysis
  • Power BI – Data modelling, DAX calculations, visualisation, and dashboard development

What I Did

I started by reviewing and preparing the raw dataset containing approximately 13,500 records. I checked the structure of the data, reviewed the columns and data types, and cleaned the dataset so it could be used reliably for analysis.

I then created a MySQL database named Commercial_Intelligence_DB and created the required tables, including the Orders table. I loaded the prepared data into SQL and worked through issues such as duplicate entries, safe-update restrictions, table visibility, and SQL syntax errors.

After loading the data, I wrote SQL queries to answer key business questions, including:

  • Total Sales
  • Total Profit
  • Sales by Region
  • Sales by Category

I then moved the data into Power BI for visual analysis. I created a dedicated Date table, established the necessary relationships, and developed DAX measures for the dashboard. I also created hierarchies to make the data easier to explore.

For the dashboard, I designed KPI cards and multiple visuals to communicate important commercial information clearly. I added slicers, drill-down functionality, drill-through pages, and a tooltip page to make the report interactive rather than simply presenting static charts.

I also focused on the dashboard's visual consistency and professional appearance. I established a consistent colour system where Navy represented Sales, Teal represented Profit, and Orange represented Cancelled orders. I adjusted font sizes, layouts, spacing, formatting, and visual interactions to make the dashboard easier to read and navigate.

During development, I tested the dashboard and troubleshot issues such as drill-through not working correctly and drill-through fields being assigned to the wrong category. I corrected these settings and refined the report until the interactive features worked as intended.

Dashboard Features

  • Sales and profit KPI cards
  • Sales performance analysis
  • Regional analysis
  • Category analysis
  • Profit analysis
  • Order-status analysis
  • Date-based analysis
  • Interactive slicers
  • Drill-down functionality
  • Drill-through analysis
  • Custom tooltip page
  • Consistent professional dashboard design

Skills Demonstrated

Data Analysis • Data Cleaning • Excel • Power Query • SQL • MySQL • Power BI • DAX • Data Modelling • Data Visualisation • Dashboard Design • Business Intelligence • Troubleshooting

Outcome

The completed Commercial Intelligence Dashboard transformed a large raw dataset into an interactive business intelligence solution. It provides stakeholders with a clear way to monitor sales and profitability, compare regions and categories, investigate detailed records, and identify patterns that can support better commercial decision-making.
```
